# Sources

One merged, deduplicated registry of every source used in the research documents
([RESEARCH_REVIEW.md](RESEARCH_REVIEW.md), [STRATEGY_CATALOG.md](STRATEGY_CATALOG.md),
[RESEARCH_LIMITATIONS.md](RESEARCH_LIMITATIONS.md)). It was built from the registries of four
evidence reviews run on 2026-10-22 (R1 to R4, see the review's method section). No source was
added here that those reviews did not list.

How to read an entry:

- **Ref**: the reference as the reviews give it. Where a review flagged a venue, volume or author
  order as unverified, that is repeated.
- **Type**: PR-OOS (peer-reviewed, with an out-of-sample test as described by the review),
  PR (peer-reviewed, in-sample or out-of-sample design not seen), WP (working paper or preprint),
  PRAC (practitioner, vendor, press), INST (central bank, regulator, international organisation),
  DOC (exchange or data-provider documentation), OWN (own measurement).
- **Read**: FT full text or its relevant sections; WP-FT full text of a working-paper version;
  ABS abstract or landing page; SUM third-party summary; SN search-engine extract only; DOC
  documentation; LIVE endpoint called live; NR not read. When reviews read a source at different
  depths, each is listed with the review that read it.
- **Origin**: the id the source had in each review (for example R1 A1 or R3 S2).

Ids are stable: new sources get new ids; ids are never reused.
