# Languages

The journal is in English or Spanish: **Settings → Language** (one setting for the whole
journal, every browser). The page reloads in the chosen language.

## How text is translated

- Text stays written in English in the code and is looked up by that English text. A
  language's dictionary maps it to the translation; text without an entry shows in English,
  so a missing entry never breaks a page.
- In React components: `const { t, tn, tx, intl } = useI18n()` (or `useT()` for `t` alone)
  from `components/i18n.tsx`.
  - `t("Add trade")`; values in braces: `t("{count} trades in {month}", { count, month })`.
    Never build a sentence by joining translated pieces: translate the whole sentence with
    its values.
  - `tn(count, "{count} trade", "{count} trades")` picks the wording for a count.
  - `tx("status", "Open")` for a word that reads differently in a context; the dictionary
    entry is `"status|Open"`, and the plain `"Open"` is the fallback.
  - `intl` (`en-US` or `es-ES`) for `toLocaleDateString` and `Intl.DateTimeFormat` month
    and weekday names. Numbers and money keep their current format (dot decimals) in both
    languages, so what you type and what you read match.
- Outside components (helpers in `lib/` that build labels or messages): `tr`, `trn`, `trx`
  from `lib/i18n.ts`, which use the journal's language.
- On the server (notifications, AI prompts): `serverT` and `serverTn` from
  `server/i18n.ts`. Error messages from the API stay in English in the code; the browser
  translates them when they arrive (`postJson`, `useApi`), so a static message needs only a
  dictionary entry.
- Text a person typed (account names, tags, notes, playbook rules) is never translated.
  Brand and product names (Binance, Yahoo Finance, TradingView, Vela, Pine Script) stay.

## Dictionaries

`lib/i18n/*.ts`, one per area of the app, merged in `lib/i18n/es-index.ts`: `common`
(navigation, shared words), `shell-settings`, `dashboard-reports`, `trades`, `charts`,
`chart-tools`, `journal-ai`, `features` (backtesting, external analysis, alerts, prop firms),
`server`. A text two areas share reads the same in both. `tests/i18n.test.ts` checks every
entry keeps its `{values}` and is not empty.
